# Telegram-бот и Mini App «ЭРА»

Облачный продукт общественной организации «ЭРА» — Объединение лидеров и культурных инициатив.

Работа идёт **в паре**: Telegram-бот (`@ERA_1bot`) для меню, уведомлений и быстрых действий; **Mini App** (`/app/`) для афиши, задач, проектов, возможностей, профиля, панелей лидера/админа и медиа. Точки входа в приложение: кнопка «🔥 Открыть ЭРА», deep links `#/events`, `#/tasks`, `#/opportunities`, `#/profile`, `#/admin…` (см. `docs/ERA_UX_SCREEN_MAP.md`, `docs/BOT_BUTTON_SURFACE_MAP.md`).

## Возможности

- регистрация участника, гостевой RSVP на годовщину, роли (участник / лидер / медиа / админ);
- личный кабинет, баллы, рейтинг, портфолио и PDF;
- мероприятия: запись, лист ожидания, посещение, календарь;
- проекты и задачи (в боте и в Mini App);
- возможности: предложения, аукцион, каталог наград, опросы;
- «Мой вектор» и прогресс участника;
- досуг: литература (серия 48 законов + редакция) и игры;
- панели лидера и администратора («Решить сегодня», люди, работа, связь);
- медиа-чат, база знаний, рассылки и аудит.

## Основные команды

- `/start` — начало работы или главное меню;
- `/menu` — главное меню;
- `/navigation` — навигация по разделам;
- `/literature_admin` — редакция литературы (по праву);
- `/leader` — панель лидера (резерв / deep link);
- `/admin` — панель администратора (резерв / deep link).

## Облачный запуск

Проект разворачивается на Render из `render.yaml`. Инфраструктура включает:

- Docker web service для Telegram webhook;
- PostgreSQL;
- Redis-совместимое хранилище Render Key Value;
- автоматический деплой после изменений в GitHub.

Секреты `BOT_TOKEN` и `WEBHOOK_SECRET` хранятся только в Render и не записываются в GitHub.

## Настройка Telegram

1. Добавьте бота администратором официального канала ЭРА для проверки подписки.
2. Добавьте бота в общий, департаментские и лидерский чаты.
3. Для модерации чатов отключите Privacy Mode через BotFather.
4. Заполните числовые ID канала и чатов в переменных Render.
5. Укажите Telegram ID администраторов в `ADMIN_IDS` через запятую.

## Локальный запуск

```bash
cp .env.example .env
docker compose up --build -d
```

Контейнер применяет миграции, запускает webhook, планировщик напоминаний и обработчики бота.

## Проверка

```bash
python -m pytest -q
```

GitHub Actions автоматически повторяет тесты после каждого обновления основной ветки.

## Безопасность

- не сохраняйте токен бота в репозитории;
- ограничивайте права администратора доверенными аккаунтами;
- согласуйте политику обработки анкет, телефонов и селфи;
- настройте резервные копии PostgreSQL перед постоянной эксплуатацией;
- проверяйте новые сценарии на небольшой тестовой группе.
