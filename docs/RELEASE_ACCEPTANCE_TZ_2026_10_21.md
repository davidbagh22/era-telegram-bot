## Правила исполнения

Сверять текущие main, PR и LIVE перед работой. Не повторять исправленное. Читать нужные файлы, сохранять checkpoint каждого этапа. Новые дефекты исправлять в текущей архитектуре. Не сбрасывать регистрацию; не создавать фиктивные production-участия/баллы и массовые тестовые рассылки; Commission bot не менять; RU/ENG не добавлять. Персональные анкеты, пароли и паспортные данные в репозиторий/логи не помещать. Локальные фикстуры не считать реальной Telegram-приёмкой.

## Матрица сценариев

1. Бот:личка/общий чат, /start, главное меню, назад/домой, ссылки на приложение. Не отправлять сообщения другим людям без согласованного сценария.
2. Регистрация:фото, продолжение после прерывания, одобрение/отклонение, отсутствие дублей. Действующую анкету владельца не сбрасывать.
3. Доступ:участник/лидер/администратор/категорийный сотрудник; чужой ID, отзыв, старая кнопка, незавершённая форма; область видимости выгрузки.
4. Задача:назначение/взятие, результат, уточнение, проверка, баллы один раз, блокер/просрочка, запрет отмены при непроверенном результате, конкурирующее решение.
5. Рассылка:предпросмотр, согласованный ограниченный canary, повторный запуск без дублей, отчёт ошибок. Массовая production-проверка запрещена.
6. Проект:черновик/возобновление/подача, разрешённый reviewer, решение, этап/вклад/подтверждение, портфолио.
7. Событие:быстрое создание с фото и мастер, предпросмотр/публикация, регистрация/отмена с подтверждением, QR/явка один раз, календарьUTC.
8. Обращение:вопрос/вложение, назначение по категории, ответ, доставка/повтор, права при переносе и отзыве.
9. Досуг:список игр, читаемые длинные варианты, запуск из актуального экрана, два игрока/команды/закрытие/награда один раз. Мафию не добавлять.
10. Литература:каталог/выпуск/назад, подписка/отписка, отметки/размышление, плановая доставка19:00Ереван, утверждение пользовательского материала, публикация без дублей.
11. Аналитика:кратко→подробно,1/7/30д, предыдущий равный период, задачи/обращения требуют внимания, совпадение с Excel на одном периоде/scope; плановый отчёт и Пульс.
12. Документы:реальный выданный сертификат/PDF, портфолио/CV, ICS, сезон/общий рейтинг; собственный экспорт данных и запрос на исправление/удаление. Нельзя создавать фиктивный сертификат в production ради теста.
