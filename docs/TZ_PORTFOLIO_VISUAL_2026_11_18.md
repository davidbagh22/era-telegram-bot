# ТЗ: визуально сильное портфолио ЭРА (PDF)

Утверждение владельца: текущий PDF «пустой», «некрасивый», «неаккуратный». Нужен **статный** документ, а не тонкий бланк.

## Проблемы текущего шаблона

1. Половина страницы — белизна; контент «висит» сверху.
2. Слабая иерархия: имя и секции почти одного веса.
3. Секции с одним словом («Председатель», «Коммуникация») выглядят как недоделка.
4. Подписи внизу оторваны от композиции — как чужой блок.
5. Бренд сведён к маленькому логотипу + строке, а не к герою документа.

## Целевой образ

**«Официальный портрет участника ЭРА»** — плотная, редакционная композиция A4:

- Тёмный бирюзовый hero-баннер на всю ширину (бренд + имя + роль).
- Двухколоночный корпус: слева мета (город, навыки, языки, счётчики ЭРА), справа биография и подтверждённая активность.
- Плотные секции без пустых заголовков: если данных мало — секция не рисуется **или** оформляется как цельный callout, а не одна строка в пустоте.
- Участия и сертификаты — первые блоки активности (как в политике ЭРА).
- Подписи/М.П. — аккуратный нижний колонтитул с линиями под ручную печать, без «залипшей» пустоты над ними.
- Без baked seal в портфолио (только открытые поля); печать+подпись — в сертификате участника.

## Цвета и шрифты

| Токен | Значение | Роль |
|---|---|---|
| Ink | `#0B1F1C` | Основной текст |
| Paper | `#FFFFFF` | Фон |
| Hero | `#0F3D38` | Баннер |
| Accent | `#1A7A6D` | Акцентные линии / метки |
| Soft | `#E7F3F0` | Плашки навыков / метрик |
| Muted | `#5B6B67` | Вторичный текст |

Шрифты: **Source Sans 3 / Inter / DejaVu Sans** (Unicode). Display-имя — крупный sans, не «газетный» serif.

## Композиция (первая страница)

1. **Hero (≈42–48 мм):** логотип ЭРА слева; справа белым — «ПОРТФОЛИО ЭРА», ФИО 22–26 pt, роль/headline, город.
2. **Колонки (gap 6 мм):**
   - **Левая 58 мм:** «Профиль», навыки-чипы, языки, KPI-карточки (мероприятия / сертификаты / проекты / роли) — только ненулевые.
   - **Правая ~118 мм:** «О себе» (если ≥2 предложений или ≥80 символов; иначе блок не показывать как одинокое слово), затем секции активности с левой accent-полосой у каждой записи.
3. **Footer:** тонкая accent-линия + примечание о подтверждении ЭРА + таблица подписей.

## Правила контента

- Не выводить секцию, если в ней 0 записей.
- «О себе» / навыки: если значение короче 12 символов и совпадает с ролью — не дублировать отдельной секцией; оставить в hero.
- Перед выгрузкой Mini App по-прежнему задаёт вопросы (headline / about / skills / languages).
- Имя файла: `Портфолио_ЭРА.pdf`.

## Критерий приёмки

Скриншот первой страницы:

1. Hero читается как бренд ЭРА даже без остального текста.
2. Нет больших «дыр» между блоками при типичном наполнении.
3. При скудных данных страница всё равно выглядит как законченный документ (hero + боковая колонка + footer), а не как наполовину пустой бланк.
4. Обложки/логотип не обрезаются криво; печать/подпись — свободные поля.

## Вне скоупа этого ТЗ

- Рекомендательное письмо — отдельный шаблон (тот же бренд, формат письма).
- Сертификат участника с печатью — уже отдельный поток.
