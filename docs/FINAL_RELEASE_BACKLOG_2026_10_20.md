## Подтверждённый остаток аналитики — первый приоритет
- admin_analytics_service.build_management_report использует meaningful_user_ids_since (ledger only при include_current_responsibility=False), а общий overview — verified facts с нулевыми баллами/attendance/project/task confirmations. Это несовместимые определения подтверждённой активности; Excel/новый overview не доказывают согласованность старой ежедневной сводки.
- meaningful_user_ids_since не имеет верхней границы периода; активность отчёта строится относительно now, а не его period_end. Нужны общие verified helpers и одинаковые [start,end) для текущего и предыдущего окна.
- commands_ready: ручные daily/weekly/monthly вызовы management_report_text не передают previous. Плановый daily передаёт предыдущий сохранённый отчёт, но renderer сравнивает только users_total. Полной динамики KPI ещё нет; исторические текущие stocks не восстанавливать задним числом.
- literature_stats: subscribed — текущая approved eligible база, active/read/task — накопительные durable markers без периода. «Активных 4 / подписчиков 2» само по себе не доказывает ошибку, но имеет разные базы. Разделить подписку сейчас, действия за период и накопительные результаты; не подменять цифровое чтение подтверждённым участием.
- management_report_text смешивает управление и техдиагностику, отображает много нулей/дат, скрывает attention после первых 3 пунктов. Основной экран: решения → главные результаты/дельты; рабочие details/Excel отдельно; healthy scheduler/backup в диагностике, аварии остаются видимыми.
- analytics_filters.analytics_waiting считает только pending users, только new questions, pending/review задачи. Нужны согласованные overdue/blockers/needs_info/waiting состояния и прямое разрешённое действие для каждого типа. Открытые attention не должны теряться из-за обрезки 3 или отличий stock definitions.
- Проверить оставшиеся legacy/extended/Excel определения и запросы целевыми тестами; не объявлять глобальное устранение N+1/индексов без проверки планов. Не создавать индексы ради формальности.
