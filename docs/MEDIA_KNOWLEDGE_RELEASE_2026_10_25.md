# База знаний медиа

Один существующий каталог MediaLibraryItem для бота и приложения: поиск, категории, текстовые инструкции, HTTPS-ссылки на документы/видео/шаблоны, закрепление, редактирование и обратимое скрытие. Нативные команды /media_knowledge и /media_knowledge слово читают тот же каталог и проверяют доступ заново. Это не новая система хранения и не автоматическая публикация в топик.

Редактируют текущий руководитель и председатель; членство, роль и устаревшая версия проверяются сервером. Создание с request UUID идемпотентно, история в AuditLog, восемь конкурентных созданий/правок проверяются на изолированной PostgreSQL. Скрытие сохраняет запись/вложения и даёт восстановление. Seed закреплён за ID существующих материалов, чтобы переименование/скрытие не создавали копии при перезапуске. Старое руководство сохраняет внутренний переход без потери Telegram initData.

Адресные проверки сервисов/API/бота и сборка выполнены локально; browser E2E и PostgreSQL probe обязательны в CI. Выпуск — только успешный CI точного SHA, expected-SHA merge и automatic LIVE с проверкой health/ready/logs. Изменение не утверждает новые литературные материалы/юридические документы и не отправляет сообщения реальным участникам в качестве теста.
