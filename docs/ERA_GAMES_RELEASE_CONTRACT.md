# ЭРА — завершение «🎮 Интерактив» (релизный контракт)

> Уточнение владельца от 15.10.2026: выпуск PR #336 разрешён после зелёного CI и Render live без входа в его Telegram. Все игры и баллы включаются для всех; ручной Telegram E2E владелец выполняет сам после выпуска. Это заменяет предварительный TESTERS / Telegram E2E в данном документе для этого релиза. Автоматические проверки и подтверждение однократных публичных доставок обязательны.

## Границы релиза
- Существующий бот, БД, points_service, темы и thread_id сохраняются.
- До Telegram E2E: FEATURE_GAMES=OFF. После ручного E2E: TESTERS, затем ALL.
- Публичный анонс — ровно один раз, только после публикации рабочего меню в существующей теме «Оповещения».
- Игроки только реальные, без фиктивных пользователей, счётчиков и баллов.

## 12 форматов (каждый — самостоятельная механика)
1. Быстрый квиз — 5 вопросов с вариантами.
2. Командный квиз — лобби, ready-check, 5 вопросов, общий итог.
3. Правда или миф — бинарный ответ и пояснение.
4. Угадай страну — 3 подсказки, баллы уменьшаются после подсказок.
5. Хронология науки и культуры — расставить 3 нейтральных события по времени.
6. Словесная цепочка — новый ответ на последнюю букву.
7. Ассоциации — угадать слово по последовательным подсказкам.
8. Логическая задача — задача с проверяемым ответом.
9. Культурный блиц — вопросы об искусстве, литературе и культуре.
10. Память — показать последовательность и воспроизвести.
11. Командная дуэль — две команды, отдельные результаты и итог.
12. Шпион — секретная роль в личке, общая локация, обсуждение и голосование.

«Мафия» в этот выпуск не входит.
Формат «Шпион» — отдельная социальная игра, не квизовый `GameMode` из примера ниже.

## Контент на 180 дней
- Для квизовых форматов: отдельный датированный набор, минимум 180 записей на формат.
- Контент хранится как версионированные JSON/CSV, с проверкой схемы и уникальности.
- Вопросы и ответы проверяются тестами; у каждого вопроса есть верный ответ и пояснение.
- Запрет повторов: ключ (пользователь, формат, контент) на 180 дней; глобальный пул не должен исчерпываться из-за других игроков.
- Запрещено считать 180 однотипных арифметических вопросов полноценным 180-дневным разнообразным контентом.
- Политика, насилие, трагические новости и URL в пользовательском тексте запрещены.

## Кодовые контракты (Python)

```python
from dataclasses import dataclass
from enum import StrEnum

class GameMode(StrEnum):
    SOLO_QUIZ = "solo_quiz"
    TEAM_QUIZ = "team_quiz"
    TRUE_OR_MYTH = "true_or_myth"
    GUESS_COUNTRY = "guess_country"
    CHRONOLOGY = "chronology"
    WORD_CHAIN = "word_chain"
    ASSOCIATIONS = "associations"
    LOGIC = "logic"
    CULTURE = "culture"
    MEMORY = "memory"
    TEAM_DUEL = "team_duel"

@dataclass(frozen=True)
class GameContent:
    content_id: str
    mode: GameMode
    prompt: str
    answer: str
    explanation: str

def validate_content_bank(items: list[GameContent]) -> None:
    for mode in GameMode:
        group = [item for item in items if item.mode == mode]
        if len(group) < 180:
            raise ValueError(f"{mode}: need at least 180 items")
        ids = [item.content_id for item in group]
        if len(ids) != len(set(ids)):
            raise ValueError(f"{mode}: duplicate content_id")
        if any(not x.prompt.strip() or not x.answer.strip() for x in group):
            raise ValueError(f"{mode}: empty prompt/answer")
```

## Обязательные тесты
- Каждый формат: старт, ход, правильный/неправильный ответ, окончание, повторный callback.
- Команды: 2–8 реальных игроков, выход, таймаут, ready-check, race на PostgreSQL.
- Идемпотентность начислений, лимиты 20/100/300, блокировки, права пользователей.
- 180-дневная уникальность на игрока и формат, очистка старых ключей.
- OFF и TESTERS не публикуют массовый анонс.
- После ALL — одна публикация в «Оповещения» с кнопкой, повторный scheduler не дублирует.
- Существующие «Мероприятия», «Литература», «Задания», рассылки не регрессируют.

## Release gates
1. Полный GitHub CI зелёный на финальном SHA.
2. Telegram E2E под авторизованным тестовым пользователем; бот имеет права на тему.
3. TESTERS: подтверждены все 11 механик и начисления.
4. Merge в main и Render live /health ok на том же SHA.
5. FEATURE_GAMES=ALL только после успешного TESTERS.
6. Проверить единственный анонс и повторную доставку scheduler.

**Этот документ — критерии готовности, а не утверждение, что механики уже реализованы.**
