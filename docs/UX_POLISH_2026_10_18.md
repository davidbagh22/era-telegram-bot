# Telegram UX: исправления по реальным скриншотам

## Изменения

- Первый экран игр: две категории одиночных форматов, вход в существующую командную тему, результаты и правила. Все 11 форматов сохранены; командные комнаты создаются только в общей теме.
- Категории и результаты переключаются редактированием текущего сообщения. Технические коды комнат не показываются в заголовках, старые callback-токены остаются действительными.
- Собственные последние игры и состав своей команды перенесены в «Мои результаты». Основной экран не содержит длинного списка участников.
- В одиночной карточке убраны собственный Telegram ID, состав из одного игрока и инструкция об одновременных ответах команды. Итог отделяет игровые очки от баллов ЭРА.
- Командные карточки сохраняют видимость состава и Telegram ID согласно согласию при вступлении. Старые безымянные записи восстанавливают подпись из публичного username либо Telegram getChat; имена из регистрационной анкеты не используются. Если Telegram недоступен, остаётся честная ссылка «Профиль Telegram».
- Результаты новых завершённых игр сохраняют публичные подписи и команды вместе с прежними очками. Старые записи не переписываются.
- Успешные бэкапы сохраняются в БД и отображаются в ежедневной/ручной статистике без отдельного сообщения на каждую попытку CI. Уведомления об инциденте и его восстановлении сохранены.
- Нижнее меню: короткая «Связь», «Статистика» для администраторов, «Досуг» для игр и литературы. Версия меню в существующих AppSetting позволяет обновить уже мигрировавший Telegram-клиент при следующем взаимодействии; после обновления повторных сообщений нет. Старые текстовые кнопки продолжают работать.
- Напоминание «Пульс недели»: период и срок разнесены по строкам; указан часовой пояс. Назначение, сроки, получатели и ключи доставки не меняются.

## Проверка и ограничения

Регрессионные тесты проверяют компактный обзор, доступность всех девяти одиночных режимов через категории (ещё два — в общей теме), редактирование карточки без новой отправки, отсутствие создания тем, восстановление публичных имён без раскрытия анкеты, отсутствие отдельных уведомлений о двух успешных бэкапах, сохранение сообщения об ошибке и однократное обновление старого меню.

Схема БД, существующие chat_id/thread_id, балансы, анкеты и история не меняются. Для отката достаточно вернуть код; дополнительные ключи версии меню и поля JSON результатов совместимы с прежним кодом.

Цвета, шрифты и размеры системных кнопок определяет Telegram и тема пользователя. Визуальный результат на реальном iOS/Android требует проверки владельцем: входить в его Telegram или имитировать участников не нужно. Изменение не подменяет оставшиеся критерии MASTER_REMAINDER.md и не означает завершение всего мастер-ТЗ.

Окончательные CI, SHA и подтверждение Render фиксируются в PR после выпуска.
